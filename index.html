Menu items and modifiers

Each item can have any number of modifier groups, including flavors, extras, and preparation. Each group can require one, permit multiple, or be optional. Names and choices are entirely customizable.

1. Upload menu CSV

Standard columns: Item Name, Category, Price, Modifier Group, Selection Type, Required, Modifier, Modifier Price, Final Price. Optional Min Selections and Max Selections give finer control. The older six-column file still imports; its modifiers get an inferred group. Every row represents one item/choice pairing. Blank Modifier creates an item with no options.

2. Add or edit item

Modifier groups

Examples: “Choose a flavor” (one, required), “Extras” (multiple, optional), “How to prepare” (one, required). Add as many custom groups and choices as needed.
