Menu items and modifiers

Upload a CSV where each row pairs an item with one modifier. Repeated item names are automatically consolidated into one menu item with a selectable modifier group. You can then add, edit, or delete items and modifier choices manually.

Modifier group

For example: “Choose a flavor” for Agua Frescas or “Cooking preference” for Hamburger. Customers choose one option when ordering.

How the CSV becomes menu data

Rows are grouped by Item Name + Category + Price. Each unique value in the Modifier column becomes an option for that item. Modifier Price is added to the base price; Final Price is optional validation data.

This preserves a simple import format while supporting price-changing choices such as “Add avocado +$2.00.” Item photos remain editable in the existing admin workflow and are represented here by a category-based placeholder.
